# DyadResearch 前端—后端一致性审计（2026-07-19）

## 结论

本轮先修复会造成错误研究结论的高风险问题，再收敛“只有界面、没有后端”的功能。生产入口为 `http://127.0.0.1:8000`。

## 审计步骤与结果

1. 数据浏览日线基线：000001.SZ 返回 614 行，范围 2024-01-02～2026-07-17。
2. 分钟周期切换：修复前选择“1分钟”只改标题、不发起查询，旧日线被错误标成分钟线；修复后选择周期立即清空旧结果并自动查询，返回 58,727 行真实分钟数据。
3. 图表缩放：修复前 K 线与成交量由两个 ECharts 实例渲染，滑块只能驱动 K 线；修复后合并为一个双网格图表，`dataZoom.xAxisIndex=[0,1]`，K 线与成交量共用时间轴和滑块。
4. 派生周期：5 分钟查询返回 144 行（三个交易日），季度查询返回 11 行；均由基础周期确定性合成，没有补造价格。
5. 因子研究：修复前四个页签重复同一内容，Winsorize、Z-Score、方向未传后端；修复后预处理参与结果哈希和实验保存，页签分别显示概览、序列、分布、稳健性。单标的无法诚实完成行业/市值中性化，因此控件被禁用并说明原因。
6. 策略研究：删除没有注册后端的假策略文件和假因子；只显示 `/api/strategies` 与 `/api/factors` 返回的真实条目。第二轮进一步加入 SQLite 持久化定义、前后端 CRUD 和受限结构化 Python 解析，策略与因子现在可以新增、编辑、保存和删除，保存版本会直接用于后续运行。
7. 回测基准：删除前端生成的模拟沪深 300 曲线；默认基准改为真实 `510300.SH`，服务端对齐 ETF 收盘净值，返回基准收益与超额收益并纳入数据指纹。
8. 可访问性/窄屏：在 762px 宽审计窗口仍存在三栏工作台横向裁切，这是桌面投研工作台的当前限制，后续应增加可折叠侧栏，而不是压缩图表。
9. 扩展数据浏览：新增真实后端与对应页签，可按证券/表/日期读取 8 类财务原始记录，并浏览板块成员与指数权重快照；数据质量页从数据库动态读取股票、ETF、财务和参考数据覆盖，而非显示静态文案。
10. 实验报告：因子实验显示覆盖率、样本数和分布摘要，回测显示收益指标；生成后的 HTML、JSON、CSV 通过受限只读路由直接打开或下载。
11. 全局入口：原先无响应的环境按钮、全局搜索、命令面板、设置和帮助均改为可操作覆盖层；命令搜索可筛选并切换五个真实工作区，设置只展示实际生效且可复现的配置，不伪造保存操作。
12. 分钟回测：研究标的早于 ETF 基准时不再用未来基准价格向前填充，而是从首个重叠 bar 对齐；同时将历史窗口、净值峰值和活跃订单扫描从平方复杂度降为线性/常数级。58,563 根真实分钟 bar 的端到端 API 回测由超时降至 17.39 秒。
13. 费用配置：回测实验和策略研究的佣金率、最低佣金、印花税率均改为可编辑并传入后端策略对象；真实成交明细验证买入佣金与卖出佣金/印花税均使用修改后的参数。
14. 低量比动量策略：新增 `low_volume_ratio_momentum`。000920.SZ 在 2026-07-16 的真实分钟数据中以涨幅 10.03%、量比 0.598、市值约 66.88 亿元触发；修正后识别其下一分钟开盘价 14.15 元为涨停价，因此正确跳过，不再产生虚假买入。
15. 全市场选股与统一费用：低量比动量策略新增沪深主板全市场模式，按日线和时点股本预筛后再读取候选日分钟线；2026-07-16～17 实测筛出 202 个证券日候选，扫描 47,959 根分钟线，得到 6 个信号、5 只股票。所有策略默认佣金万一且 5 元起步，卖出印花税万五。
16. 全市场执行规则修正：策略改为信号出现后的下一分钟仅判断一次；开盘涨停、停牌或无成交均直接跳过，不允许订单延迟到后续分钟成交。每只股票按当时总资产的 20% 建仓，最多同时持有 5 只。2026-07-01～17 的 86 个真实信号中，70 个下一分钟开盘涨停、16 个下一分钟不可交易，因此成交 0 笔、策略收益 0%；这取代了旧规则下不真实的 5 笔成交和 14.06% 收益。
