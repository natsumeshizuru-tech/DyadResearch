# DyadResearch 论文复现

本项目只研究两篇论文：Kakushadze (2015) 的 101 个公式化 Alpha，以及
国泰君安 (2017) 的 191 个短周期价量因子。

目标是把公开公式转化为可审计的软件资产，并明确区分：

- 公开公式与算子语义；
- 依赖专有数据、历史股票池和行业分类的原文数值；
- 含显式假设的透明重建；
- 受 A 股 T+1、整手、涨跌停、停牌和费用约束的可执行迁移。

!!! warning
    公式账本条目齐全不代表全部公式已经通过实现测试。请以每条记录的
    `formula_status` 和验收报告为准。历史或模拟结果不构成投资建议。

| 论文 | 账本 | 本地可比性 |
| --- | ---: | --- |
| 101 Formulaic Alphas | 101 | B（公式/数据市场不同）或 D（A 股迁移） |
| 国泰君安短周期价量多因子 | 191 | C（透明重建）或 D（A 股可执行迁移） |

项目不发布原始 PDF、私有行情数据库、账户信息或券商 SDK。
