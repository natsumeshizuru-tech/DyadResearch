# Point-in-Time 策略

- 财务记录仅在 `announcement_date <= as_of_date` 时可见；无有效公告日的记录在严格模式下不可见。
- 同一证券/表/报告期存在多个版本时，选择 as-of 时点最后公告的版本；不得按今天已知的最终版本回填历史。
- 同一报告中的多行用 `row_ordinal` 保留，版本选择不会误删合法明细行。
- 公司行动仅按当时已知且已生效的事件调整。
- 板块与指数成分当前只有 2026-07-17 快照。任何早于该日期的历史成分查询必须抛出 `PointInTimeUnavailableError`。
- 当前证券目录不能证明完整退市历史集合，因此不得宣称幸存者偏差已完全消除。
