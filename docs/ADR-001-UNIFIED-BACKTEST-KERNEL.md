# ADR-001：统一回测内核

状态：Accepted

## 背景

源项目有两套互不完全兼容的回测实现。继续分别修补会让策略语义、成交成本和结果复现不断漂移。

## 决策

DyadResearch 只建立一个 `BacktestEngine` 与一个 `Broker`。原生 SDK 和 QMT `init/handlebar` API 通过适配器转成相同的策略回调、订单意图和数据视图。策略适配器不实现撮合、资金、费用或公司行动逻辑。

内核提供三个显式策略：

- `strict_research`：默认，下一根可交易 bar，严格 PIT，T+1、整手、停牌/涨跌停、成交量参与率、部分成交、冻结资金全部启用。
- `qmt_compat`：保留相同无未来函数边界，在字段形状和常用下单接口上贴近 QMT。
- `legacy_compare`：仅用于与源项目 golden 结果比较，所有差异写入报告。

## 后果

结果可能与任一旧内核不完全相同，但差异可通过 policy、输入 manifest 和事件日志解释。任何新成交特性只实现一次并由所有适配器共享。
