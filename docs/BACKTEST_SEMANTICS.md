# 回测语义

默认 `strict_research` 每个时间片按以下顺序执行：

1. 跨日结算，将昨日买入数量转为可卖。
2. 应用当日已知且生效的公司行动。
3. 使用当前 bar 撮合此前已提交且已满足延迟的订单。
4. 把成交事件反馈给策略。
5. 用当前收盘价盯市。
6. 向策略发布当前 bar；此时下单最早在下一根可交易 bar 成交。
7. 执行到期的确定性调度回调。
8. 校验现金、冻结资金、持仓数量和总资产恒等式并记录权益。

买入默认 100 股整手；卖出允许清仓零股。A 股 T+1 默认启用。停牌、无成交量、一字涨停买单和一字跌停卖单不成交。成交量参与率决定单 bar 最大数量，未成交部分保留为活动订单。买单提交时冻结估算现金，卖单提交时冻结可用持仓；取消或终结时释放。

市价单用下一 bar 开盘价加方向性滑点；限价单仅在价格触达时，以对策略更保守且不越过限价的价格成交。系统默认佣金为成交额万一且每笔最低 5 元，卖出印花税为成交额万五；佣金、最低佣金、印花税和过户费均使用 `Decimal`。
